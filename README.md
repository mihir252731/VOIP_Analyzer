# VoIP Analyzer

VoIP Analyzer is a Python-based network forensics and traffic inspection project for capturing and analyzing SIP/RTP VoIP traffic. It parses packet captures, extracts protocol metadata, highlights suspicious behavior, and can generate PDF reports to support troubleshooting, monitoring, and security-focused analysis.

## Included In This Upload Folder

- Source code
- Requirements file
- Runner scripts
- Small sample capture files

## Excluded To Stay Under 25 MB

- `venv/`
- `__pycache__/`
- Generated log/report files
- Large sample capture: `data/captures/nitroba-1.pcap`

## Install

```bash
pip install -r requirements.txt
```
